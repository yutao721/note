# web端截屏方案

## 1. html2canvas

### 1.1 介绍

[html2canvas](https://github.com/niklasvh/html2canvas) 是一个可以将 HTML 转化为 Canvas 的库，它支持将整个页面或者部分页面转化为 Canvas，然后可以将 Canvas 转化为图片，或者将 Canvas 保存为 PDF 文件。

### 1.2 使用

```js
import html2canvas from 'html2canvas';

html2canvas(document.body).then(canvas => {
  // 将 Canvas 转化为图片
  const imgData = canvas.toDataURL('image/png');
  const img = new Image();
  img.src = imgData;
  document.body.appendChild(img);
});
```

### 1.3 优点

- 支持将整个页面或者部分页面转化为 Canvas
- 支持将 Canvas 转化为图片或者 PDF 文件
- 使用简单，只需要引入库并调用相应的方法即可

### 1.4 缺点

- 性能较差，对于大型页面或者复杂的页面可能会出现卡顿或者失败的情况
- 不支持一些复杂的 CSS 效果，比如动画、渐变等
- 不支持一些复杂的 HTML 元素，比如 SVG、Canvas 等
- 不支持一些复杂的 JavaScript 操作，比如动态加载的内容等
- 不支持一些复杂的 HTML 结构，比如嵌套的 iframe 等

## 2. dom-to-image

### 2.1 介绍

[dom-to-image](https://github.com/tsayen/dom-to-image) 是一个可以将 DOM 节点转化为图片的库，它支持将整个节点或者部分节点转化为图片，然后可以将图片保存为文件。

### 2.2 使用

```js
import domtoimage from 'dom-to-image';

domtoimage.toPng(document.body)
  .then(dataUrl => {
    const img = new Image();
    img.src = dataUrl;
    document.body.appendChild(img);
  })
  .catch(error => {
    console.error('oops, something went wrong!', error);
  });
```

### 2.3 优点

- 支持将整个节点或者部分节点转化为图片
- 支持将图片保存为文件
- 使用简单，只需要引入库并调用相应的方法即可
- 支持一些复杂的 CSS 效果，比如动画、渐变等
- 支持一些复杂的 HTML 元素，比如 SVG、Canvas 等
- 支持一些复杂的 JavaScript 操作，比如动态加载的内容等

### 2.4 缺点

- 性能较差，对于大型节点或者复杂的节点可能会出现卡顿或者失败的情况
- 不支持一些复杂的 HTML 结构，比如嵌套的 iframe 等
- 不支持一些复杂的 HTML 元素，比如 video 等

## 3. modern-screenshot

### 3.1 介绍

[modern-screenshot](https://github.com/qq15725/modern-screenshot) 使用 HTML5 canvas 和 SVG 从 DOM 节点快速生成图像
Fork from [html-to-image](https://github.com/bubkoo/html-to-image)

### 3.2 使用

```js
import { domToPng } from 'modern-screenshot'

domToPng(document.querySelector('#app')).then(dataUrl => {
  const link = document.createElement('a')
  link.download = 'screenshot.png'
  link.href = dataUrl
  link.click()
})
```

## 4. html-to-image

### 4.1 介绍

[html-to-image](https://github.com/bubkoo/html-to-image) 是一个可以将 HTML 转化为图片的库，它支持将整个页面或者部分页面转化为图片，然后可以将图片保存为文件。Fork from [dom-to-image](https://github.com/tsayen/dom-to-image) with more maintainable code and some new features.

### 4.2 使用

```js
import * as htmlToImage from 'html-to-image';
import { toPng, toJpeg, toBlob, toPixelData, toSvg } from 'html-to-image';


const node = document.getElementById('my-node');

htmlToImage
  .toPng(node)
  .then((dataUrl) => {
    const img = new Image();
    img.src = dataUrl;
    document.body.appendChild(img);
  })
  .catch((err) => {
    console.error('oops, something went wrong!', err);
  });
```
